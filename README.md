# Mushroom Timer 🍋🍄

## In this repository
1. QSS files for style, you can choose from pastel-style (periwinkle 💙) and colorful-style (green and yellow 🍋🍏) or style, with full pixel art theme (or custom files). 
2. assets: fonts, pixel-art mascots, pixel art custom buttons for the app, sound file
3. core: timer model
4. utils: reusable functions
5. ui: app pages, stacked window and widgets
6. config.py: all the constants, changes are possible to customize the app
7. main.py file
8. requirements.txt for the virtual environment

## How to use the app
### With main.py
1. Clone the repository
2. Create a virtual environment
3. Install the requirements
4. Run main.py and start working!

Also possible to customise the app & add stuff !

### Install the app with PyInstaller
- Install PyInstaller in the virtual env
- Run pyinstaller --windowed main.py
- In main.spec: add the QSS files and assets folder in data, add icon and app name.
