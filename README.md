# Mushroom Timer 🍋🍄

## In this repository
1. QSS files for style, you can choose from pastel-style (periwinkle 💙) and colorful-style (green and yellow 🍋🍏) or style, with custom files. 
2. assets: fonts, pixel-art mascots, pixel art custom buttons for the app, sound file
3. python files: source code for the app
4. requirements.txt for the virtual environment

## How to use the app
### With the source code
1. Clone the repository
2. Create a virtual environment
3. Install the requirements
4. Run main.py and start working!

Also possible to customise the app with the source code & add stuff !
